## 迭代目标

把「**业务方怎么写前端**」这件事从零变成可复制的基线 —— 前端包不再是占位，
`can()` 有真实数据源，路由守卫能拦住越权访问，主题令牌不再硬编码。

Sprint 3 复盘的三条教训直接写进了本迭代的出口标准：
1. **让 QA 在 Dev 动手前写用例并挑验收标准的毛病** —— 本迭代的流程强制项
2. **修漏洞会制造新漏洞** —— 修复轮后必须有**独立复核**（不由修复者自验）
3. **注释与代码不一致比没有注释更坏** —— 注释里写「也覆盖 X」必须有变异验证支撑

## 迭代出口标准

| 出口标准 | 状态 | 证据 |
|---|---|---|
| **REQ-011 全部 12 条 AC** | ⬜ | QA 用例集逐条执行；首轮 + 修复轮**各一次独立复核** |
| 当前用户有效权限点可从后端读到 | ⬜ | `GET /api/rbac/me/permissions`；未认证 → 401 |
| 登录响应带真实权限点 | ⬜ | 有角色 → 非空；无角色 → `[]`（不是 null、不是缺字段） |
| 前后端 `can()` 判定一致 | ⬜ | 同一组权限点，两边判定结果**相同** |
| `<Can>` 无权限时**不渲染**（不是 display:none） | ⬜ | DOM 里查无该内容 |
| 路由守卫拦得住**直接敲 URL** | ⬜ | 绕过前端跳转，直接访问路径仍落 403 页 |
| 401 自动刷新**并发只刷一次** | ⬜ | 5 个并发请求 → 刷新接口被调 **1** 次（否则轮换机制会踢人下线） |
| 幂等键**每次新生成** | ⬜ | 两次相同写请求 → 两个**不同**键（复用会导致静默丢数据） |
| 主题令牌 = CSS 变量，无硬编码颜色 | ⬜ | 机械扫描 `packages/theme` + `packages/ui` 源码 |
| 包依赖单向，无交叉 | ⬜ | `@base/sdk` 不依赖 `@base/ui`；`ui → theme` 单向 |
| 依赖预算不增长 | ⬜ | `Cargo.lock` 包数 = **295**（不引 utoipa / MSW / Storybook） |
| 回归确定性 | ⬜ | Rust 全绿且 **N passed > 0**；前端全绿；至少连跑 2 轮 |

## 环境备注（低配机）

- 开发机 8 线程 i7-8550U / 7.7G 内存 / **4.7G 可用** / 磁盘剩 109G
- **Rust 编译串行执行**（`.cargo/config.toml` 固定 `jobs = 3`）
- 复用 target 目录：`export CARGO_TARGET_DIR=/home/myg133/Projects/system_seed/code/target`
- 容器用 rootless podman，**不用 docker**
- 镜像必须用 `docker.m.daocloud.io/` 显式前缀
- 第三方依赖树 **284**（`Cargo.lock` 共 295 包）
- **断电后必须手工恢复**：bus watcher + podman 容器（都不会自启）
  → 见 [dev-guide-low-spec.md](../plan/dev-guide-low-spec.md) §8.5
- ⚠️ `cargo test` **只能有一个 `--`**（双 `--` → 0 passed 假绿）
- ⚠️ 应用连接**必须用普通角色 `base_app`**（超管会被 `require_isolation` 拒绝启动，退出码 3）
- ⚠️ 前端断言**必须断「等于期望值」**，不能只断「不等于默认值」（D83）
