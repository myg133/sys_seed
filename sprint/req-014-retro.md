## 1. 教训（按「可复用的程度」排序）

### 1.1 🔴 **「数字相等」不等于「集合相等」** —— BA 自己写的判据，被 Dev 用一次实现就撞出来了

- **经过**：F10 要求断言「`TITLES` 的码集合 == i18n `error.*` 的码集合」。
  两侧**恰好都是 84** → BA 以为它们是同一个集合。
  Dev 一实现就撞上 **6↔6** 的差集，按停止条件**没有自行改成弱化版本**，上报 BA 裁决。
- **真相**（BA 逐条读源码核实）：
  - `TITLES` = **78 个错误码** + **6 个组织事件码**（`org.*`）= 84
    —— `titles.rs` 的模块注释**明写**「组织事件码沿用既有 `org.*` 形式」；
  - i18n `error.*` = 那 78 个 + **6 个当前不进 HTTP 响应体**的码 = 84
    （3 个启动期环境诊断码 + 3 个 `platform-core::error::CoreError` 的码）。
  - → **两侧的差集都是有意为之**，集合相等**永远不成立**。
- **裁决**：D194 —— 改判「**包含**」关系（每个会进响应体的错误码，TITLES 与 i18n 都要登记），
  并**同时查 `en-US.json` 与 `zh-CN.json`**（只查英文的话中文少一条抓不到）。
- **可复用**：**写跨栈断言前，先把两侧的「构成规则」读清楚**。
  这次的构成规则就写在源文件的模块注释里，BA **没读**。
- **讽刺之处**：L-04 提这条问题的原话就是「计数相等会掩盖『少一个、多一个』的互换」——
  **BA 把「计数相等掩盖」写成了「集合相等」**。

### 1.2 🔴 **skip 状态下不得声称该功能已验证**（新增流程规则 D193）

- **经过**：Dev 报「E2E **30 passed / 5 skipped / 0 failed**」，全绿。
  但那 **5 条 skip 正好包含**审计页的翻页与过滤用例 → **B-01 / B-02 在交付时完全没被发现**。
- **裁决**：D193 —— D108 管「能不能 skip」，**D193 管「skip 了之后怎么说话」**：
  1. skip 本身**仍然合规**（系统未就绪时 skip 是对的）；
  2. 报告必须把「真跑通过」与「skip」**分开列**；
  3. **处于 skip 状态的功能不得计入「已验证」** —— 交付前必须让系统就绪后**真跑一遍**。
- **可复用**：「全绿」这个词必须带上**分母**。`30 passed / 5 skipped` 不是「全绿」。

### 1.3 🔴 **脏库会掩盖缺陷** —— 测试必须在**干净起点**上跑，且要有**负向对照**

- **经过**：修复轮 2 的 Dev 报「E2E **35 passed / 0 failed**」，
  但那是**脏库**（tenant-a 被历史运行累积到 **42 条**）下的结果。
  独立复核在**干净库**（seed 只播 **11 条** < 默认 limit **20**）上发现：
  「回退」用例**必然失败**（按钮 `disabled` → 点击超时）。
  - 根因：那条用例**没调页大小**，偷偷依赖「tenant-a 记录数 > 20」；
    同文件的上一条用例**显式**写了 `selectOption('10')` 并注明原因 → **漏了一行**。
- **裁决**：F11 补那一行 + **负向对照**（删掉那行 → 同一干净库上复现失败 → 还原）。
- **可复用**：
  1. 任何依赖「数据量 > N」的断言，**要么自己造数据，要么显式把 N 调小**；
  2. 「全绿」要附**起点状态**（本次：`tenant-a = 11`）；
  3. 修复的证据不应该是「跑出来是绿的」，而应该是
     **「没有它就会红」**（负向对照）。

### 1.4 🟠 **「登记在骗人」** —— 登记值必须与行为一致（D182 / D186）

- **经过**：Pre-merge 复验发现 `audit.page.defaultSize` 在
  `manifest.json` 登记 **50**、在迁移里写 **`'50'::jsonb`**、而运行时 `DEFAULT_LIMIT` 是 **20**。
  运维在配置面板看到 50，实际接口返回 20 → 排查时走错方向。
- **裁决**：D182 把登记值改 20，D186 落地。
- **延伸**（复核 M-01）：补的那条断言**注释说「三处来源」，代码却只比了两处**
  （第 2 处用的是硬编码常量，不是运行时常量）→ **注释与代码不一致**。
  复核的实验证明：把 `DEFAULT_LIMIT` 漂到 30，**那条断言仍然绿**。
- **裁决**（D194 同源思路）：在**装配层**（`platform-server`，同时依赖 audit 与 config）
  补一条**真正把三者接起来**的断言；config 侧那条改注释说清它实际覆盖两处。
  ⚠️ `platform-config` **不得**依赖 `platform-audit`（分层是刻意的）。

### 1.5 🟠 **引用契约时，要区分「它要求什么」与「我以为它要求什么」**

BA 在这一轮里**两次**栽在这上面，都是**同一个病根**：

| 次数 | BA 写的 | 契约实际 | 后果 |
|---|---|---|---|
| 1 | 「C6 要求 `application/problem+json`」 | **C6 只钉错误体的形状**，没规定 Content-Type | 判据写错（Dev 抓出） |
| 2 | 「C9 只要求层级用 `.` 分隔」 | **C9 还要求键名 camelCase** | **配置键名写 snake_case → 服务起不来** |

- **可复用**：**契约没写的 ≠ 契约要求的**。
  引用契约时，除了读「它写了什么」，还要读「**它没写什么**」。

### 1.6 🟡 **回归口径本身会错** —— 「11 crate」漏了一个，而且漏的那个**正好相关**

- **经过**：整个 REQ-014 周期（3 轮 Dev + 2 轮 QA + BA 终验前的所有轮次）
  的回归清单都写「**11 crate**」，而 workspace 实际有 **13** 个成员、**12 个**有测试。
  漏掉的是 **`platform-contracts`** —— 它有 `tests/c6_schema_projection.rs`，
  而 **C6 正是错误响应契约**，REQ-014 恰恰改过错误响应。
- **BA 终验时补跑**：**32 passed / 0 failed** → 无回归（虚惊一场），但**口径是错的**。
- **可复用**：**回归清单要数 workspace 成员，不要手抄**。
  同样地，**crate 的包名 ≠ 目录名**：`modules/sandbox` 的包名是 `sandbox`
  （写成 `platform-sandbox` → `cargo test` 直接 rc=101、**0 条结果、还看不出来**）。

### 1.7 🟡 **注释与代码不一致比没有注释更坏**

本轮出现 **3 次**：
1. `query.rs` 的模块注释仍写「违反契约 C6 的 `application/problem+json` 要求」（D183 已推翻）；
2. F3 断言的 doc 写「三处来源」，代码只比两处（1.4）；
3. Dev 主报告说 F10「未落地」，而工作区**已落地**（报告 12:45 写，小报告 12:56 写，**自相矛盾** 11 分钟）。

- **裁决**：F13 —— 订正报告**并留痕**（「这不是当初就写对了」）。
  报告是**证据链**的一部分，改了就要留痕，**不能抹掉原始结论**。

### 1.8 🟡 **「BA 不是裁判，BA 也是被审的对象」**

- 本轮 BA 自己被查出 **4 处规格缺陷**：D181（配置键名）、D183（Content-Type 判据）、
  D192（F10 集合相等）、以及**规格 rev 4 之前 D180 正文里残留的 C6 误述**。
- **每一次都是被 Dev / QA 抓出来的，不是自己发现的。**
- **可复用**：BA 的裁决**必须写清「依据是什么」**，好让执行方**能反过来发现 BA 错了** ——
  本轮之所以能抓到，是因为 BA 每次都把 `file:line` 和契约条款写进了裁决里。

### 1.9 🟢 **变异自证是唯一能证明「判据不是死代码」的手段**

- 本轮共 **15+ 处**变异（5 + 3 + 6 + 1，BA 终验再亲做 2 处），每一处都证明：
  「把那一行改坏 → 对应断言变红 → 还原后逐字节相同」。
- 其中 **2 处特别有价值**：
  - **M4**（去掉 `pg_advisory_xact_lock`）→ 真的**分叉**了（两条都拿 genesis）
    → 证明并发用例抓得住；
  - **反向变异**（失败分支的 `user_agent` 置空 → 用例仍绿）→ 挖出一个**真实的覆盖缺口**（L-01）。
    → **正向变异证明「抓得住」，反向变异证明「还有哪儿抓不住」**。
- **可复用**：修复时**必须**同时交两样：① 判据；② 判据的敏感度证据。
