# 接入方 AI 提示词

四个阶段各一个 prompt。用法：把对应文件整段粘给接入方的 AI，再补上"你的现状"与"要接入的系统"。

| 阶段 | 文件 | 产出 | 前置 |
|---|---|---|---|
| 设计 | `01-design-review.md` | 接入方案（不写代码） | 拿到契约包 |
| 实现 | `02-implement.md` | 可运行模块 + 自测结果 | 方案已确认 |
| 自检 | `03-self-check.md` | 准入包草稿 + 证据 | 功能完成 |
| 排障 | `04-troubleshoot.md` | 根因 + 修复 + 回归用例 | 联调出现异常 |

三条使用原则：

1. **让 AI 引用章节号**（如"按 §13.3 的组件目录"），否则它会自由发挥。
2. **让它跑命令再下结论**（`contract-verify`、curl、日志），不要接受"应该可以"。
3. **红线写进 prompt**（不解析 JWT、不自建审计表、不共享库），每轮都带。
