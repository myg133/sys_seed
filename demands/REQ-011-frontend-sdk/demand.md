## 功能要求

- @base/ui：表格、表单、树、穿梭、图表、上传、编辑器、弹窗、布局（基于 shadcn-svelte + token 层）
- @base/sdk：类型安全 API client（自动刷新 token、错误拦截、幂等键注入）
- @base/auth：登录态、当前用户、can()、路由守卫、<Can> 组件
- @base/theme：设计令牌、暗色模式
- @base/i18n：多语言
- @base/hooks：分页、表格状态、SSE/WebSocket、剪贴板
- OpenAPI → 类型生成，纳入 CI
- Storybook + Vitest + Playwright + MSW 基线

## 不在范围内

- 元数据驱动的动态表单/列表渲染器（见 REQ-012）
