## 功能要求

- 结构化日志 + trace_id 贯穿请求 / 日志 / 消息
- OpenTelemetry 指标与链路、错误上报
- 健康检查 / 就绪探针
- API 版本化、统一错误格式（RFC 9457）、分页/排序/过滤规范、幂等键
