## 需求描述

统一文件存取，并让大批量导入导出异步可回溯。

本需求是 REQ-001「通用项目底座」的拆分子项，负责其中的一个能力域。

## 依赖

以下前置需求需先完成（依赖关系见 [roadmap.md](../../plan/roadmap.md)）：

## 功能要求

- 对象存储抽象层：S3 / MinIO / OSS / 本地
- 上传下载、预签名 URL、分片、断点续传
- 图片处理、病毒扫描钩子
- Excel / CSV 模板下载、异步导入导出、错误行回执、导入预览与校验

## 不在范围内

- 报表导出（见 REQ-019）
- **S3 真连**（只做 SigV4 协议，无 MinIO 环境）→ **TD-059**
- **Excel（.xlsx / .xls）**（需 ZIP + XML 库）→ **TD-060**
- **图片处理**（缩略图 / 裁剪）→ **TD-061**
