## 判据区分力分级（本集的重点）

以下 **8 条**是「实现改坏了会红」的核心判据，实现时**必须逐条确认能变红**：

| 用例 | 判什么 | 变异方式 |
|---|---|---|
| TC-018-008 | `object_key` 在签名覆盖范围内 | 不签 key → 红 |
| TC-018-026 | 超限**无副作用**（落盘为空） | 改成「写完再删」→ 红 |
| TC-018-027 | 默认扫描是 `skipped` 不是 `clean` | 默认返回 `clean` → 红 |
| TC-018-040 | **进度每批更新** | 只在最后写一次 → 红 |
| TC-018-047 | 导出 round-trip | 不转义逗号 → 红 |
| TC-018-050 | **四张表**各验 RLS | 只验 3 张 → 第 4 张漏 |
| TC-018-051 | `tenantScoped` 恰好 4 个 | 写成「包含」→ 漏第 4 张也绿 |
| TC-018-055 | `all_codes()` 源码 grep | 只看测试绿 → 漏加也是绿 |
