## 需求描述

实现 ADR A3 的本地账号体系与凭证生命周期，SSO 另立需求。

本需求是 REQ-001「通用项目底座」的拆分子项，负责其中的一个能力域。

## 依赖

以下前置需求需先完成（依赖关系见 [roadmap.md](../../plan/roadmap.md)）：

- REQ-002
- REQ-006

## 功能要求

- 本地账号：注册、登录、登出、密码找回与重置、首次登录强制改密
- 密码策略：长度 / 复杂度 / 有效期 / 历史不重复
- Access / Refresh Token 分离与轮换、撤销列表、登出全端失效
- 设备会话管理：会话列表、单设备下线、全局下线
- MFA：TOTP + WebAuthn
- 登录失败限流与账号锁定、图形/短信验证码
- JWT 签名密钥轮换（kid + JWKS 发布）

## 不在范围内

- SSO 入站协议（见 REQ-013）
- 注册策略的租户级配置（见 REQ-010）
