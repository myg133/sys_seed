# 需求：SSO 多协议与出站 IdP

- **需求编号**: REQ-013
- **父需求**: [REQ-001 通用项目底座](../REQ-001-platform-foundation/demand.md)
- **优先级**: P1
- **状态**: 草稿
- **所属迭代**: Sprint 4
- **更新时间**: 2026-11-17 23:45

## 需求描述

打通入站 SSO 与出站 IdP 两条路，让底座既能接企业 IdP，也能给第三方应用发令牌。

本需求是 REQ-001「通用项目底座」的拆分子项，负责其中的一个能力域。

## 依赖

以下前置需求需先完成（依赖关系见 [roadmap.md](../../plan/roadmap.md)）：

- REQ-007
- REQ-009

## 功能要求

- 入站（底座作 SP）：SAML 2.0、OIDC / OAuth2、LDAP / AD、CAS
- 出站（底座作 IdP / OAuth2 Provider）：授权码 + PKCE、Client Credentials、Device Code
- JWKS 发布与令牌内省（introspect）
- 免登跳转：应用间携带令牌直接跳转
- 强制 SSO 策略：租户可禁用本地密码登录
- 单点登出：全局登出 / 按应用登出

## 不在范围内

- SSO 登录页定制（见 REQ-010）
