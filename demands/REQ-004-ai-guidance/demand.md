## 需求描述

让 AI 辅助开发能直接产出符合平台约定的代码，而不是重造底座已有的轮子。

本需求是 REQ-001「通用项目底座」的拆分子项，负责其中的一个能力域。

## 功能要求

- 仓库级 AGENTS.md：架构约定、编码规范、可用命令、禁止事项
- 模块级 AGENTS.md 骨架，由 create-module 生成
- prompts/ 提示词库：按任务成套（新建模块 / 加权限点 / 接 SSO / 定义流程 / 通知模板 / 越权测试 / 测试用例 / 性能优化）
- capabilities/ 机器可读能力索引：权限点、扩展点签名、元数据 JSON Schema、SDK 用法、OpenAPI 清单
- xtask capabilities 从 manifest + trait + OpenAPI 自动生成索引
- create-module 脚手架：目录 + manifest 模板 + AGENTS.md 骨架 + 契约测试接入
- CI 校验索引与源码一致；平台核心变更在 PR 中打标强制人工评审

## 不在范围内

- 提示词的具体业务内容（按项目补充）
- 多端规则文件转换脚本的细节
