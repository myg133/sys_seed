# 需求：多租户与隔离

- **需求编号**: REQ-006
- **父需求**: [REQ-001 通用项目底座](../REQ-001-platform-foundation/demand.md)
- **优先级**: P0
- **状态**: 草稿
- **所属迭代**: Sprint 2
- **更新时间**: 2026-11-17 23:45

## 需求描述

实现 ADR A2 的租户隔离，并让跨租户访问在数据库层被挡住。

本需求是 REQ-001「通用项目底座」的拆分子项，负责其中的一个能力域。

## 依赖

以下前置需求需先完成（依赖关系见 [roadmap.md](../../plan/roadmap.md)）：

- REQ-002

## 功能要求

- 租户 CRUD、开通/停用、租户级配置
- L1 隔离：共享表 + tenant_id + PostgreSQL RLS 策略
- 隔离级别抽象层：为 L2 独立 schema / L3 独立库预留接口
- 租户上下文中间件：请求头解析 → 上下文注入 → DB / 缓存 / 消息 / 日志全链路携带
- 跨租户运营后台：租户开通、套餐、配额、用量
- 配额与限流：存储空间、API 调用次数、并发数

## 不在范围内

- 租户级品牌配置（见 REQ-010）
- 租户级 SSO 策略（见 REQ-013）
