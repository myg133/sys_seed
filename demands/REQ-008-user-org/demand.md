## 需求描述

管理用户实体与组织树，并支持与外部系统双向同步组织架构。

本需求是 REQ-001「通用项目底座」的拆分子项，负责其中的一个能力域。

以下前置需求需先完成（依赖关系见 [roadmap.md](../../plan/roadmap.md)）：

- REQ-007

## 功能要求

- 用户 CRUD、状态管理（启用/禁用/离职）
- 组织树：公司 / 部门 / 小组、岗位、汇报关系
- 出站 SCIM 2.0：Users / Groups 端点，把底座组织推给第三方
- 入站 LDAP / AD 定时拉取，增量 + 全量对账
- 冲突处理策略：底座为准 / 外部为准 / 进人工待处理队列
- 离职自动禁用账号；组织变更事件推送给受影响用户
