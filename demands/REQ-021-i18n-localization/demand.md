## 需求描述

让底座从第一天起就是多语言 / 多时区 / 多币种的，而不是事后改造 —— **事后补国际化是最贵的返工**。

本需求是 REQ-001「通用项目底座」的拆分子项，负责其中的一个能力域。

## 依赖

- REQ-006（多租户 —— 语言/时区/币种是租户级配置）
- REQ-010（配置 —— 承载租户级偏好）
- REQ-011（前端 SDK —— `@base/i18n` 与渲染器）
- REQ-012（元数据渲染 —— 字段 label 也需要本地化）

> ⚠️ **本需求会修改 REQ-011 的交付物**（D109：跨需求的包改动必须显式声明）：
> `packages/sdk/src/index.ts` 的 `ApiError` **新增 `params` 字段**（现在只有
> `code` / `status` / `title` / `detail`）—— 不加则前端拿不到参数、渲染不出完整文案。
> **提交信息里必须写明这一点。**

## 交付边界（本轮，经用户拍板）

### 范围内

1. **后端零翻译** —— 错误体**不含**面向用户的中文，只返回 `code` + `params`
   （**`title` 收敛到集中映射表 `TITLES`**，见 D113 与 design §2）
2. **语言协商** —— **用户显式偏好 > `Accept-Language` > 租户配置 > 平台默认**
   > ⚠️ **起草时我写反了**（原本写「Accept-Language > 用户偏好」）。
   > 想清楚后：**用户在我们系统里显式设的偏好最权威** ——
   > 他设了 English 就该看英文，不管浏览器语言是什么。
   > `Accept-Language` 只是「用户没设时的最佳猜测」。见 design §3.1。
   >
   > **协商结果必须可观测**（D110）：`GET /api/i18n/context` → `{locale, timezone, currency, source}`
3. **翻译键体系** —— 键的命名规则 + 单一来源
4. **缺失键回退** —— 回退基准语言 + **记录**，不出现空白、不泄露 key 原文
5. **租户级偏好** —— 语言 / 时区 / 币种走 REQ-010 的 config（`scope: tenant`），
   并**新增配置值的 `format` 校验**（D111，否则 `timezone=Not/AZone` 会 200 落库）
6. **时区** —— 时间存 UTC（已有），按用户/租户时区**渲染**；同一时间点在不同时区正确
   （**渲染只在前端**，D114 —— 后端无 tzdb，只做值的校验与存储）
7. **币种（工具 + 汇率表）** —— `Money` 类型（**整数最小单位，零浮点**）+
   格式化 + **汇率快照表** + 整数换算
8. **前端 `@base/i18n`** —— 翻译加载 / 切换 / 回退，
   **单一实现**（组件零硬编码文案，不要求 SSR/CSR 一致 —— 项目是纯 CSR，那条不可验）

### 不在范围内（**明确延后**）

- **通知模板 / 邮件 / 导出文件的国际化** —— 依赖 **REQ-015（通知）** 与
  **REQ-018（导出）**，两者**均未开工**。本轮做会定义一套注定返工的形状。
  > **用户拍板（2026-11-19 19:00）**：明确延后，不在本轮做假接口。
- **业务模块自身的领域术语翻译** —— 业务模块自行维护，但接入同一键体系
- **后端渲染本地化文案**（邮件正文、PDF 报告）—— 与上一条同因
- **第三方翻译服务接入**（DeepL 等）—— 键体系稳定后再议

## 功能要求

### 后端

- **错误体零中文**：`title` 从集中的 `TITLES` 表取英文；`detail` 本就是英文 ASCII（已有）
  —— **实际是 70 处**（55 处由函数产出 + 15 处构造点字面量），不是 8 处
- `Accept-Language` 解析与协商（BCP 47，支持 `zh-CN`, `en-US`, `zh-CN;q=0.9`）
- **协商结果观测通道**：`GET /api/i18n/context` → `{locale, timezone, currency, source}`
- 租户级 `locale` / `timezone` / `currency` 通过 config 声明（`scope: tenant`）+ **`format` 校验**
- **`Money` 类型**：`{ minorUnits: i64, currency }`，**不做浮点运算**
- **汇率快照**：`platform_fx_rate` 表（`from` / `to` / `rateMicros` / `asOf` / `source`）
- 跨币种换算**必须带快照引用**（可追溯「用的是哪一天的汇率」），**兑换中间量用 `i128`**

### 前端

- `@base/i18n`：翻译资源加载、语言切换、缺失键回退（+ 记录：`onMissingKey` / `missingKeys()`）
- 按 locale 格式化日期 / 数字 / 货币（**用 `Intl`**，不自造），小数位数由**货币 exponent** 决定
- 时区渲染：同一 UTC 时间点按用户/租户时区显示（**只在前端**）
- 语言偏好：用户级存 `sessionStorage`（切换即生效，**不跨设备**）

## 完成定义

- **语言协商链路通**（四级优先级可验，且 `source` 可观测）
- **错误体零中文**（跨全部模块，`TITLES` 表 + `ALL_CODES` 完备性测试保底）
- **多时区渲染一致**（前端渲染，跨日例子可区分）
- **金额零浮点误差**（整数相等断言，不是「差值 < eps」）
- 缺失键回退**可观察**（`onMissingKey` + `missingKeys()`，测试可机械断言）
