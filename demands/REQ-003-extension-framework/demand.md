## 需求描述

建立业务模块与平台之间的唯一接缝：trait 扩展点 + 自动注册 + 可执行的契约测试。

本需求是 REQ-001「通用项目底座」的拆分子项，负责其中的一个能力域。

## 功能要求

- 扩展点 trait 定义（Repository / Service / Auditable / NotificationSender / WorkflowHandler 等首批）
- 编译期自动注册（inventory / linkme），模块声明即被发现
- 运行时装载：模块有启停开关，未启用不加载
- platform-contracts 契约测试套件：租户上下文、权限点登记、方法完整性、事务边界
- 平台核心标记 crates/platform-core/，业务模块对其直接修改由 CI 拦截

## 不在范围内

- 具体业务模块实现
- 扩展点 API 语义化版本策略（随发布流程）
